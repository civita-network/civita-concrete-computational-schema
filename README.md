# civita-concrete-computational-schema

Part of CIVITA, the Computational Infrastructure for Validation, Integration, Testing, and Assessment.

Authoritative schemas and controlled vocabularies for computational models, simulation configurations, numerical results, and scientific provenance within CIVITA.

This component is under development. The detailed scientific schema will be developed separately.
